🧠 lil bit abt mata kuliahku 

Pengembangan Game adalah mata kuliah yang mengajarkan dasar-dasar dan praktik pengembangan game menggunakan berbagai engine.
Dalam repositori ini, tugas-tugas difokuskan pada:

🎯 Pembuatan game 2D & 3D sederhana

🧩 Pemrograman gameplay dengan GDScript (Godot) & Lua (Roblox)

🎨 Desain level, karakter, dan aset visual

🕹️ Interaksi pemain dan antarmuka (UI/UX)

🚀 Testing dan publikasi game sederhana

🧰 Tools yang Digunakan
Platform	Bahasa	Deskripsi Singkat
🕹️ Godot Engine (v4.x)	GDScript	Game engine open-source dengan dukungan 2D dan 3D.
🧱 Roblox Studio	Lua	Platform game berbasis komunitas dengan dukungan multiplayer dan scripting interaktif.
